# Glosario

| Término | Definición |
|---|---|
| **Marca** | Fabricante comercial (p. ej. Tesla, BYD, Renault). |
| **Modelo** | Producto comercial de una marca (p. ej. Model 3). |
| **Versión** | Variante concreta de un modelo, con specs propias (batería, motor, tracción). |
| **BEV** | Battery Electric Vehicle: 100 % eléctrico. Es el alcance de esta web. |
| **PHEV** | Híbrido enchufable. _Fuera de alcance salvo decisión contraria._ |
| **Autonomía WLTP** | Autonomía homologada según el ciclo WLTP europeo, en km. |
| **Capacidad útil** | kWh de batería realmente utilizables. |
| **Carga AC / DC** | Potencia máxima de carga en corriente alterna / continua, en kW. |
| **Segmento** | Clasificación por tamaño (A, B, C, D, E, SUV…). |
| **Mercado** | País o región donde una versión se comercializa. |
